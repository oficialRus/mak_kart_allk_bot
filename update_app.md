# Обновление приложения на сервере

Команды, которые нужно выполнить самому (по порядку).

---

## 1. Подтянуть новые изменения

```bash
git pull
```

## 2. Установить зависимости (если менялся package.json)

```bash
cd mini_app
npm ci
```
или, если не сработает:
```bash
npm install
```

## 3. Собрать приложение

```bash
npm run build
```

## 4. Выложить на сервер

- Содержимое папки **mini_app/dist** скопировать в каталог веб-сервера (nginx, apache, хостинг и т.д.).
- Либо перезапустить сервис, который раздаёт приложение (PM2, IIS и т.д.), если он сам подхватывает собранные файлы.

После этого приложение на сервере будет с новыми изменениями.
