# Mini App — тест (MAK Kart)

Мини-приложение Telegram для опросника. Открывается **внутри Telegram** по кнопке «Открыть тест» (кнопка с типом Web App, не обычная ссылка).

## HTTPS в режиме разработки

Dev-сервер запускается по **HTTPS** с самоподписанным сертификатом (плагин `@vitejs/plugin-basic-ssl`). После `npm run dev` приложение доступно по **https://localhost:5173**. При первом заходе браузер покажет предупреждение о сертификате — можно принять и продолжить.  
**Важно:** Telegram (и многие клиенты) не доверяют самоподписанным сертификатам, поэтому для кнопки «Открыть тест» внутри Telegram по-прежнему нужен публичный HTTPS (ngrok или деплой на Vercel и т.п.).

## Локальный запуск (чтобы открывалось внутри Telegram)

Telegram открывает Mini App только по **HTTPS**. Для проверки на своём компьютере:

1. В папке `mini_app`: `npm install` и `npm run dev` (сервер на http://localhost:5173).
2. Запустите [ngrok](https://ngrok.com/): `ngrok http 5173`.
3. Скопируйте HTTPS-адрес (например `https://abc123.ngrok.io`) в корневой `.env` проекта бота:
   ```
   MINI_APP_URL=https://abc123.ngrok.io
   ```
4. Перезапустите бота. Кнопка «Открыть тест» будет открывать приложение внутри Telegram.

## Сборка и деплой

```bash
npm run build
```

Папка `dist/` — статика. Залить на любой хостинг с HTTPS (Vercel, Netlify, GitHub Pages, свой сервер).

После деплоя добавьте в корневой `.env` проекта бота:

```
MINI_APP_URL=https://ваш-домен.com
```

Или укажите полный URL до вашего Mini App (например `https://your-app.vercel.app`).
